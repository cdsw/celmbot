# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-21

### Added

- Localhost-only agent playground with Monaco editor, file tree, and local git panel
- Folder jail + allowlisted verification recipes (not a free shell)
- Cloud/Local key pools with per-key rate queues, cooldown, and capability probe
- Solo and sandbox orchestrator runs with approval cards, SSE timeline, and usage stats
- Unit, jail, fake-LLM integration, and Playwright API smoke tests
- Docs: TRUST, KEYS, MODELS, ROADMAP, LIVE_SMOKE, ARCHITECTURE, ADR 0001
- CI workflow (typecheck, lint, unit, jail, e2e)
